# pagerly_user (Resource)

A person in the on-call directory: who can be paged, and the number Pagerly dials.

## Example Usage

```hcl
resource "pagerly_user" "alice" {
  email        = "alice@example.com"
  name         = "Alice"
  phone_number = "+447700900123"   # or a bare number with country_code
  role         = "member"
}
```

Creating a user that already exists adopts it. Changing `role` needs an admin key.

## Schema

### Required

- `email` (String) Email address, the directory key. Changing it recreates the user.

### Optional

- `country_code` (String) Country calling code, e.g. `+44`, for a bare phone number.
- `name` (String) Display name.
- `phone_number` (String) Phone number, in E.164 (`+4420…`) or bare with `country_code`.
- `role` (String) Directory role, e.g. `member` or `admin`.

### Read-Only

- `id` (String) Same as the email.

## Import

The import id is the user's email.

```shell
terraform import pagerly_user.alice alice@example.com
```
