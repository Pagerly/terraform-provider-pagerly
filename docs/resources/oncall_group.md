# pagerly_oncall_group (Resource)

A group on-call (multi-mention team): one name that stands for the on-call of several
teams, optionally keeping a Slack user group in step and always including some people.

## Example Usage

```hcl
resource "pagerly_oncall_group" "backend" {
  name            = "Backend"
  team_ids        = [pagerly_team.payments.id, pagerly_team.platform.id]
  user_group      = "S0123456789"
  permanent_users = ["cto@example.com"]
}
```

## Schema

### Required

- `name` (String) Group name. Cannot contain `:`, `;` or `,`.
- `team_ids` (List of String) Teams whose on-call the group stands for.

### Optional

- `permanent_users` (List of String) Emails of people always included, whoever is on call.
- `user_group` (String) Slack user group id (`S…`) kept in step with the group's on-call.

### Read-Only

- `id` (String) Same as the name, so it changes when the group is renamed.

## Import

The import id is the group's name.

```shell
terraform import pagerly_oncall_group.backend Backend
```
